### 3. Decisions to Value Methodologies

**Start with the business decision. Size the opportunity. Identify what needs to change.**

- **6Ds:** Drivers → Defect → Diagnosis → Drilldown → Doable → Dashboard
- **Decision Loss:** The value lost when a recurring decision underperforms the best feasible alternative
- **Five Levels of Decision Intelligence:** Performance visibility → Root cause intelligence → Strategic trade-off decisions → Automated decisioning → Enterprise optimisation
- **Decision Architecture:** Roles, decision rights, constraints, incentives, data, tools and workflows that shape decision quality

These approaches connect commercial opportunity identification with practical AI transformation and value realisation.
